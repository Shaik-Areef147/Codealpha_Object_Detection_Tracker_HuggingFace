# 🚀 Object Detection using YOLOv8

## 📌 Project Overview
This project is an AI-powered Object Detection Web Application built using YOLOv8, Python, and Gradio. The system allows users to upload images and automatically detects objects present in the image using a pre-trained YOLOv8 model.

The detected objects are highlighted with bounding boxes, labels, and confidence scores. The application is deployed on Hugging Face Spaces for easy access and demonstration.

## ✨ Features
- Upload images through a web interface
- Real-time object detection using YOLOv8
- Bounding boxes around detected objects
- Confidence score display
- User-friendly interface with Gradio
- Deployed on Hugging Face Spaces

## 🛠 Technologies Used
- Python
- YOLOv8 (Ultralytics)
- Gradio
- OpenCV
- NumPy
- Pillow
- Hugging Face Spaces

## 📂 Project Workflow
1. Upload an image.
2. YOLOv8 processes the image.
3. Objects are detected automatically.
4. Bounding boxes and labels are generated.
5. The processed image is displayed to the user.
